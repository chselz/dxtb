# Frozen GFN0-xTB numerical oracles

These JSON fixtures are compact extracts from the workspace `references/*`
outputs generated by xTB 6.7.1 revision `edcfbbe`. They contain only geometry,
atomic charges, component/total energies, and the printed MO data needed by
the GFN0 implementation tests.

Regenerate them from the workspace root with:

```console
python dxtb/tools/freeze_gfn0_references.py
```

CI and the dxtb runtime must never read the sibling `references` or `gfn0`
directories. Each fixture records the original command, charge/spin, units,
legacy conversion constants, and starting float64 tolerances. Large-system
orbital tables contain only the non-elided entries printed by xTB.
